# Mobile redesign

Status: idea. Noted 2026-10-16. Experiment first, change later.

## Why

The app works on phones but does not feel comfortable to use there yet.

## Plan

1. Use the app on a phone for a while and write down what gets in the way, page by page (For you, All, Profile,
   Onboarding, Landing).
2. Try alternatives before changing anything: navigation (bottom tab bar instead of the sidebar sheet?), thumb reach
   for the main actions, card density, filters on small screens.
3. Turn the findings into a feature plan.
